# 数独挑战 - 微信小游戏

一款功能完整的数独益智游戏，支持微信小游戏运行环境。

## 功能特性

### 核心玩法
- 9×9 标准数独盘面
- 宫格使用曲线区分 3×3 宫格
- 选中高亮：同行、同列、同宫高亮显示
- 冲突检测：冲突数字红色背景+波浪线标记

### 游戏模式
- **普通模式**：简单/中等/困难 三种难度
- **每日挑战**：基于日期种子的固定题目，所有玩家题目相同
- **关卡模式**：1-100 关，难度逐步上升

### 功能
- 数字键盘 1-9 + 删除按钮
- 计时器
- 暂停/继续
- 自动存档
- 重置功能
- 智能提示
- 最佳记录

### 反馈
- 通关烟花特效
- 新纪录提示

## 项目结构

```
├── game.json     # 微信小游戏配置
├── game.js       # 游戏主逻辑
└── README.md     # 项目说明
```

## 运行方式

1. 下载微信开发者工具
2. 新建项目，导入本目录
3. 选择"小游戏"类型
4. 使用微信开发者工具预览/调试
